# List of components for ESP32 ESP-IDF

## Communications

1. [zh_network](https://github.com/aZholtikov/zh_network) ESP-NOW based mesh network.
2. [zh_espnow](https://github.com/aZholtikov/zh_espnow) ESP-NOW interface.
3. [zh_syslog](https://github.com/aZholtikov/zh_syslog) Syslog server UDP client.
4. [zh_ota_server](https://github.com/aZholtikov/zh_ota_server) Simple OTA server.

## Systems

1. [zh_vector](https://github.com/aZholtikov/zh_vector) Vector (dynamic array).
2. [zh_json](https://github.com/aZholtikov/zh_json) JSON serialization.
3. [zh_menu](https://github.com/aZholtikov/zh_menu) Multi-level hierarchical menu.

## Peripherals

1. [zh_encoder](https://github.com/aZholtikov/zh_encoder) Rotary encoder.
2. [zh_pcf8574](https://github.com/aZholtikov/zh_pcf8574) PCF8574(A) I2C 8-bit I/O expander.
3. [zh_pcf8575](https://github.com/aZholtikov/zh_pcf8575) PCF8575 16-bit I/O expander.
4. [zh_pca9548a](https://github.com/aZholtikov/zh_pca9548a) PCA9548A 8-channel I2C switch.
5. [zh_cd74hc4067](https://github.com/aZholtikov/zh_cd74hc4067) CD74HC4067 16-channel analog multiplexer/demultiplexer.
6. [zh_ac_dimmer](https://github.com/aZholtikov/zh_ac_dimmer) AC dimmer 115V/400Hz.
7. [zh_inclinometer](https://github.com/aZholtikov/zh_inclinometer) Inclinometer (via optical rotary encoder).
8. [zh_tachometer](https://github.com/aZholtikov/zh_tachometer) Tachometer (via rotary optical encoder).
9. [zh_mpr121](https://github.com/aZholtikov/zh_mpr121) MPR121 touch sensor.
10. [zh_ttp229](https://github.com/aZholtikov/zh_ttp229) TTP229 touch pad (via RMT driver).
11. [zh_tm1637](https://github.com/aZholtikov/zh_tm1637) TM1637 led drive (via RMT driver).

## Sensors

1. [zh_aht](https://github.com/aZholtikov/zh_aht) AHT family humidity & temperature sensor.
2. [zh_dht](https://github.com/aZholtikov/zh_dht) DHT11/DHT22/AM2302/AM2320 humidity & temperature sensor.
3. [zh_bh1750](https://github.com/aZholtikov/zh_bh1750) BH1750 ambient light sensor.
4. [zh_onewire](https://github.com/aZholtikov/zh_onewire) 1-Wire interface.
5. [zh_ds18b20](https://github.com/aZholtikov/zh_ds18b20) DS18B20 temperature sensor.

## Displays

1. [zh_1602a](https://github.com/aZholtikov/zh_1602a) LCD module 1602A.
2. [zh_160x_i2c](https://github.com/aZholtikov/zh_160x_i2c) LCD module 1602(4)A via I2C connection (PCF8574).
